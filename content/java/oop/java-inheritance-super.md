## 一、继承(Inheritance)与 super

继承:子类继承父类的属性和方法;子类既可以使用父类成员,也可以扩展 / 重写这些成员。

**意义**

1. 代码复用,减少重复
2. 支持多态:允许在不同类对象上调用相同方法

**语法**

- `extends`:Java 只允许继承一个父类
- `super`:在子类内部引用父类

### 1.1 声明子类

![声明子类](/images/java/inheritance-declare.png)

### 1.2 访问父类成员变量

- 如果子类**没有**定义同名字段:直接 `字段名` 或 `this.字段名` 即可访问父类字段
- 如果子类**定义了**同名字段(字段隐藏):
  - 直接 `字段名` 得到的是子类字段
  - 必须 `super.字段名` 才能拿到父类字段

### 1.3 访问父类方法

**3.1 访问的不是构造方法**

**(1)访问的不是静态方法**

- 子类没有重写:直接 `方法名(...)` 调用父类方法
- 子类重写了:只能 `super.方法名(...)` 调用父类版本,是通过对象引用调用(运行阶段决定是哪个对象)

**(2)访问的是静态方法**

1. 子类没有重写这个静态方法,那么直接用 `父类名.方法名()`。如果你要用 `super.方法名()` 也可以,但是它仍然是父类名调用,不是对象引用调用
2. 子类重写了这个静态方法(被隐藏),用 `super`

**3.2 访问父类构造方法**

- `super()`:父类无参构造
- `super(参数...)`:父类有参构造
- 规则:`super(...)` 只能写在子类构造方法的第一句

  > 原因:初始化顺序必须先初始化父类部分,再初始化子类部分

### 1.4 赋值(向上转型)

假设 `Person` 是 `Man` 的父类:

![向上转型示例](/images/java/upcasting.png)

- `Person PM_1 = man_1;` **成立且安全**:这叫向上转型(编译器自动允许)
- 继承保证子类拥有父类全部成员,因此安全
- 只允许调用父类(指 `Person` 类)中已有的字段和方法,不允许调用父类中没有的字段和方法

### 1.5 父类引用指向子类对象

(其实和 1.4 是同一件事)

![父类引用指向子类对象](/images/java/parent-ref-child.png)

- 变量类型是 `Person`,但实际在内存里创建的是 `Man` 对象
- `=` 的作用:把 `Man` 对象的地址赋给 `p2`
- 执行构造函数:执行 `Man` 的构造函数
- 调用非构造方法:
  - 如果子类重写过:执行子类版本
  - 如果没重写但父类有:执行父类版本
  - 如果父类没有该方法:调用会报错(不管子类是否有定义,取决于引用类型能否看到)

## 二、注意事项

1. `super` 绝对不能在静态方法中使用,因为 `super` 代表当前对象的父类引用,依赖对象实例;静态方法属于类,不依赖于任何对象,没有 `this` 也就没有 `super`
2. 子类用 `super` 调用父类方法的时候,如果方法没有被子类隐藏(指子类创建一个与父类中该方法同名且参数列表也相同的方法),或者被子类重写,直接调用方法名即可;如果重写或者隐藏了,就要用 `super.方法名` 了,字节码会在父类方法中查询对应方法
3. `super()` 调用必须放在子类构造器的第一行
4. `super` 不是一个对象,不能将 `super` 赋值给变量
5. **面试常考**:「子类构造器中是否必须调用 `super()`?」答案是——如果父类没有无参构造器,子类必须显式调用 `super(参数)`
