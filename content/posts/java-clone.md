## 一、克隆是什么，为什么要克隆

克隆是将对象复制一份。

为什么？为了保证原始数据不被修改。

在 Java 中，如果一个对象要支持克隆的话，你必须让这个类实现一个接口，也就是类名后面加 `implements Cloneable`，而且这个接口里一个方法都没有，这玩意叫**标记型接口**。

标记型接口是:JVM 如果看到这个类上有这接口就会给你克隆对象，如果没有的话就不会给你克隆对象。

## 二、浅拷贝

- 如果是基本数据类型的话是直接复制一个值过去，而不是复制一个地址
- 如果是引用类型的话，由于一个引用类型的对象的地址 A 里面存储的是另一个地址 a，就是直接找另一个地址 B 创建对象，并且在这个 B 地址里面存储地址 a

![浅拷贝示意](/images/java/clone-shallow.png)

所以你一旦改掉了克隆对象的地址里的地址里的值，原本的对象的地址里的地址里的值也会被修改。

**这是不安全的。**
