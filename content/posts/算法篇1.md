## 一、数组

### 1.1 静态数组

#### 定义与用法

```java
// 定义
int[] arr = new int[10];

// 索引赋值
arr[0] = 0;

// 索引取值
int a0 = arr[0];
int a1 = arr[1];
```

#### 内存模型

```java
int[] arr = new int[10];
```

这行代码做了两件事:

1. 在内存中开辟了一块大小为 `10 * sizeof(int)` 的**连续空间**;
2. 将这块空间的首地址命名为 `arr`(也就是说,`arr` 是一个指向这块内存空间首地址的指针)。

所以当你要定位数组的 `arr[n]` 时,就是去查找内存中地址为 `arr + n * sizeof(int)` 的位置所存放的元素。

#### 对静态数组的操作

**增加元素**

1. 数组未满(不需要扩容)
   - 在末尾追加,时间复杂度 **O(1)**
   - 在非末尾追加,时间复杂度 **O(n)**
2. 数组已满(需要扩容)
   - 时间复杂度 **O(n)**

**删除元素**

1. 删除末尾元素,时间复杂度 **O(1)**
2. 删除非末尾元素,时间复杂度 **O(n)**

**改**

- 给定索引,修改该索引的数值,时间复杂度 **O(1)**

**查**

- 给定索引,查询该索引的数值,时间复杂度 **O(1)**
