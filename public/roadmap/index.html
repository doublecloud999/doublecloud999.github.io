一、Java 基础#

数组、编码、类加载等入门阶段最容易忽略、但面试常问的细节。

  • 细节拾遗:数组的声明与初始化 — 声明不指定大小、长度为 0 与 null 的区别
  • 数组工具类 Arrays 与 for-each — Arrays.toString/equals、数组扩容、增强 for 的三个坑
  • 细节拾遗:编码、快捷键与其他 — return 里 new 对象、sc.close()、IDEA 快捷键、编码与字节数、.length 与 .length()

二、面向对象#

整个 Java SE 的主干，也是面试问得最密的一块。

2.1 类与对象#

  • 类与对象基础:this、包、访问权限与封装 — this、import/package、四种访问修饰符、封装三原则
  • 内部类:静态嵌套类与非静态内部类 — 两者的创建方式与常见错误写法

2.2 方法#

  • 方法重载与重写 — 重载三条件、重写硬性规则、@Override

2.3 继承与多态#

  • 继承与 super — 字段隐藏、super 访问父类成员、向上转型
  • 多态 — 编译时多态与运行时多态、三个成立条件
  • 抽象类与接口 — abstract、interface、default 方法冲突
  • final、finally 与 finalize — 三个容易混的概念，以及 finally 的返回值覆盖

2.4 常用类#

  • 字符串三兄弟:String、StringBuilder 与 StringBuffer — 不可变性、扩容机制、线程安全取舍
  • 包装类型与自动装箱拆箱 — 缓存范围、空指针、性能开销
  • Object 类与 equals 重写 — Object vs Objects、哪些类重写了 equals
  • clone:浅拷贝与深拷贝 — 标记型接口、深拷贝必须层层取值

2.5 异常#

  • 异常处理 — Throwable 体系、受检与非受检、throw/throws/try-catch-finally

2.6 枚举、泛型与反射#

  • 枚举 enum — 枚举是 final 类、构造方法必须 private、values()/valueOf()
  • 泛型 — 泛型类/接口/方法、类型擦除、桥方法、通配符

2.7 JVM 相关#

  • 常量池 — 字面常量与符号常量、class 文件常量池与运行时常量池
  • 类加载器与类加载过程 — 三类加载器、双亲委派、加载-链接-初始化
  • 细节拾遗:super、静态绑定与字符串常量池 — 局部变量表第 0 槽、Integer 缓存、访问权限边界

三、集合框架#

  • 集合框架与 List — Collection / List / Set / Map、ArrayList 与 LinkedList、迭代器、并发修改异常

四、IO 与文件#

  • IO 与文件流 — 流的分类、字节流/字符流、节点流/过滤流、缓冲流/对象流
  • 序列化 — 序列化与反序列化、四类使用场景、所处协议层次

五、并发多线程#

  • 多线程入门 — 进程与线程、四种创建方式、生命周期与锁池、JVM 内存结构

六、数据库#

MySQL 笔记还在整理中，补全后上线。

七、算法与数据结构#

  • 算法笔记:链表、双指针与区间和 — 通用注意细节、链表拆节点、二分查找、移除元素、平方排序、长度最小子数组、螺旋矩阵、区间和

八、Agent#

  • Agent 入门:AgentLoop、PEAS 与三种推理范式 — 智能体循环、环境四特性、ReAct / Plan and Solve / Reflection、采样参数与 token、幻觉、Decoder-Only 与自注意力
