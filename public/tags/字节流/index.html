Java IO 与文件流

一、什么是流 流是 Java 中用于输入输出的基本机制。IO 是 Input / Output(输入输出)的缩写。 1.1 流的分类 按方向 输入流:数据从其他地方读到内存 输出流:从内存写到其他地方 按单位 字节流:处理二进制数据,如图像、音频。字符流能处理的,字节流都能处理。以 Stream 结尾的通常是字节流 字符流:处理字符数据,用于文本文件(字节流能处理的,字符流不一定能处理)。以 Reader、Writer 结尾的一般是字符流 按功能 节点流:具有读写数据的功能,位于 IO 体系最底层,直接与特定的数据源(如磁盘文件 / 网络 Socket / 内存数组)建立连接,执行最原始的读写操作 过滤流:对节点流进行封装并增强功能(数据缓存 / 对象转换)。不能与数据源建立连接,只能包在节点流外部,对节点流的功能做增强 1.2 字节节点流 操作单元:byte[] FileInputStream:一次从流中读取多个字节,read 方法返回实际读到的字节数,读到文件尾部时返回 -1 FileOutputStream:一次写多个字节 1.3 字节过滤流 操作单元:byte[],但提供了 readInt()、writeObject() 等高级数据类型的封装方法。 缓冲流 BufferedInputStream:一次读多个字节,read() 返回读到的字节数,读到文件尾部时返回 -1。加入了缓冲区功能以提高 IO 效率,减少访问磁盘的次数 BufferedOutputStream:一次写多个字节,加入缓冲区以提高 IO 效率,减少访问磁盘的次数 对象流 ObjectInputStream:一次读多个字节,增加了将数据直接转换成八种数据类型和对象的功能 ObjectOutputStream:一次写多个字节,增加了将数据直接转为八种数据类型和对象的功能 1.4 字符节点流 FileReader:能一次从流中读取多个字符,返回读到的字符数,读到文件尾部时返回 -1 FileWriter:能一次写多个字符 1.5 字符过滤流 字符缓冲流 BufferedWriter:能一次写多个字符,支持输出换行符,能一次写一行;增加缓冲区功能以减少 IO 次数 BufferedReader:能一次读取多个字符,增加缓冲区功能,支持识别行结束符 \n、\r、\r\n,能一次读一行,减少 IO 次数 注意:BufferedReader 返回的字符串中不包含换行符。 ...
