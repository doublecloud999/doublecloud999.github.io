一、通用注意细节 数组起手一定要判断数组为空或者长度为 0 的情况 Java 采用的是值传递 在 LeetCode（以及所有算法题）里,子数组（Subarray）必须是原数组中连续的一段——不连续的只能叫子序列 二、链表 通过每个节点上的 prev 和 next 指针,将零散的内存块串联起来形成一个链式结构。 提升内存利用效率 用的时候能连上:new 一个新 ListNode 对象出来,改一下前后结点指针;不用的时候可以拆掉 2.1 拆掉非尾部节点 单链表:即便你已经有了要删除结点的引用,也不能直接找到前驱节点;只能从头遍历找到前驱节点以后再删,时间复杂度 O(n) 双链表:只要有了要删除的节点的引用,直接: node.prev.next = node.next; node.next.prev = node.prev; 时间复杂度 O(1) 2.2 拆掉尾部节点 单链表:必须从头遍历找出哪个节点的 next 的 next == null,然后将这个节点的 next 设置为 null,时间复杂度 O(n) 双链表:尾部节点有自己的 prev 指针。只要找到哪个节点的 next == null,然后将这个节点的 prev 的 next 设置为 null 即可,时间复杂度 O(1) 三、练习 3.1 二分查找 要求 nums[] 一定是有序数组（升序或者降序）。通过 nums[left]、nums[right]、nums[mid] 来逐步缩减查找范围。 左闭右闭: right = nums.length - 1; 循环条件:left ≤ right 左闭右开: right = nums.length 3.2 移除元素 题目:给你一个数组 nums 和一个值 val,你需要原地移除所有数值等于 val 的元素,并返回移除后数组的新长度。 ...
