Final

Java final、finally 与 finalize

一、final 表示不可变性,可以用于类、方法、变量等不同的上下文。使用 final 关键字标记的元素只能被赋值一次,而且必须显式赋值,不能被继承、修改、重写、重新赋值。 1. 基本类型变量:值不能被修改 2. 引用类型的变量:地址绝对不能变,但是地址里存的东西可以变 final int[] arr = new int[]{1, 2, 3}; // 可以：arr[0] = 1; // 不可以：arr = new int[]{4, 5}; 3. 不可变方法 —— 不可被重写 public final void f_Method() { } 不能被子类重写。 注:private 方法加 final 没意义。private 方法对子类不可见,即便子类中重新写了一个一模一样的方法也不会报错,不算重写,这算子类写的新方法。 4. final 类 —— 不能被继承 public final class FClass { } 注意,final 类中的所有方法都是隐式 final 的。但是类内字段(类内没有自己另加 final 的字段)不受影响,基本类型能随便改值,引用类型能随便改指向的地址。 5. final 方法绝对不能是抽象的 二、finalize Object 类的方法,在垃圾回收器回收对象之前调用,用于清理资源,但是已经弃用。 三、finally 是异常处理机制的一部分。只要 try 或者 catch 没有调用 System.exit() 导致 JVM 直接退出,finally 代码块就必须执行,无论是否发生异常。 ...
