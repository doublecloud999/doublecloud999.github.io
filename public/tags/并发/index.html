Java 多线程入门

一、进程与线程 1.1 进程 OS 中的独立执行单元，包括正在执行的程序、数据和系统资源 每个进程有独立内存空间，不同进程之间不可以直接共享数据 1.2 线程 是进程内的执行单元，是操作系统分配 CPU 时间的基本单位 同一个进程内的线程可以共享相同的内存空间和资源 Java 线程与操作系统内核线程是 1:1 映射关系 1.3 两者的区别 进程是独立的执行单元，有独立内存空间，进程之间通信需要额外机制 线程是进程内的执行单元，共享进程的内存空间，线程之间可以直接共享数据 注意： 进程是 OS 进行资源分配的基本单位，在 JVM 启动的时候，操作系统为它分配独立的内存空间（虚拟地址空间）、文件描述符等等资源 线程是 OS 进行 CPU 调度的基本单位，线程存在于进程内部，共享进程的内存地址空间 1.4 JDK > JRE > JVM JDK（Java 开发工具包）⊃ JRE（Java 运行环境）⊃ JVM（Java 虚拟机）。 1.5 HotSpot JVM HotSpot JVM 是目前 Java 生态中最主流、使用最广泛的 Java 虚拟机（JVM）的具体软件实现。 即时编译器（JIT，Just-In-Time Compiler）。在运行过程中，它会持续监控代码的执行频率。如果某段代码（例如循环体或频繁调用的方法）被执行得非常频繁，它就会被标记为“热点代码（Hot Spot Code）”。 一旦被标记为热点，JVM 就会将这段字节码直接编译成当前操作系统底层的机器码，并进行深度优化。这样后续执行这段代码时，就不需要再通过解释器，从而极大提高了运行速度。 二、线程创建方式 创建线程的方式：4 种（本页详细展开前两种）。 2.1 方式一：继承 Thread 类，重写 run() 方法 创建线程分 2 步： ...
