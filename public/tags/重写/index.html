Java 方法重载与重写

一、重载(Overload) 条件 必须在同一个类中 方法名相同 参数列表不同(参数个数 / 参数类型 / 参数顺序,任意一项不同即可) 注意 返回值类型、访问修饰符不是重载条件(可以相同,也可以不同) 二、重写(Override) 子类中写一个与父类方法名相同、参数列表相同的方法。 注:父类的 private 方法不能被子类重写。 2.1 重写硬性规则 子类重写方法的访问权限不能比父类更严格(public / protected / default / private) 子类重写方法的返回类型: 必须与父类一致,或者 是父类返回类型的子类(协变返回类型) 基本类型和 void 没有「子类」概念 子类的参数列表必须与父类相同(个数、类型、顺序都必须一样) 2.2 @Override 注解 不是必须,但建议加上:方法名 / 参数写错时会直接报错提醒你。

Java 多态

多态:允许不同的对象对同一个方法进行调用(同名方法在不同对象上表现不同)。 一、编译时多态 —— 静态多态(方法重载 Overload) 编译的时候就确定用什么。 必须在同一个类中 方法名必须相同 参数列表必须不同(包括类型 / 个数 / 顺序都可以不同,只要有一个不同就算不同) 编译的时候通过参数确定调用哪个方法 二、运行时多态 —— 动态多态(方法重写 @Override) 运行的时候才决定用什么。 成立条件:3 个缺一不可 继承关系:子类继承父类 方法重写:子类重写了父类的方法 父类引用指向子类对象:Person p = new Student() 或者 Person p = man_1; 子类 @Override 父类方法,名字和参数列表必须与父类一模一样;返回值类型必须与父类的返回值类型相同,或者是父类返回值类型的子类;访问权限不能比父类更严格。 重点 调用的时候调用的方法是子类定义的方法,不是父类定义的方法 成员变量(字段)不参与多态,也不能被子类重写 静态方法和 private 方法不参与多态,因为它们压根没法被子类重写(静态方法可以被子类隐藏)。它们绑定在类上,在编译阶段就被确定好了 静态方法被子类隐藏 子类可以写一个跟父类方法名和参数列表都相同、返回值类型与父类相同或者是其子类、限制符号不比父类严格的静态方法,但是不能加 @Override 注解,这会直接导致编译报错。 而且这不叫重写,没有多态效果。
