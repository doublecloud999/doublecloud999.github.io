抽象类

Java 抽象类与接口

一、抽象类:abstract 不能被实例化的类(不能被创建对象),通常包含抽象方法,但也可以有普通方法和字段。 可以写的修饰符:public / protected / default。严禁: private:因为抽象类本身存在的意义就是被子类重写,子类根本看不到 private 方法,矛盾,编译报错 static:属于类,不能被子类重写 final:和「抽象方法必须被重写」的要求冲突,编译报错 1.1 抽象方法定义 没有方法体(就是只有 (),没有 {})的方法,只包含方法名称和参数列表 抽象方法必须在抽象类中声明,由具体的子类提供实现 1.2 子类实现抽象方法 继承抽象类 重写抽象方法,并提供抽象方法的具体实现 写抽象类时要想清楚:哪些是子类必须实现的(写成抽象方法);哪些是子类可以直接继承的(写成普通方法)。这是设计层面的难点。 1.3 要注意的点 如果一个非抽象子类继承了一个抽象父类,它必须重写父类中所有的抽象方法;如果继承了抽象父类的子类没有重写所有父类中的抽象方法,那么这个子类必须被声明为抽象类 abstract,否则直接编译失败。要求类的继承链在到达末端(可以实例化的具体类)之前,必须完成所有抽象方法的具体实现 抽象方法只有方法名,没有方法体 {},不能被 private / static / final 修饰 抽象类里不一定有抽象方法,但是可以有构造方法(供子类 super() 调用),用来初始化继承来的字段 abstract class Animal { String name; Animal(String name) { // 抽象类的构造方法 this.name = name; // 初始化继承给子类的字段 } } class Dog extends Animal { Dog(String name) { super(name); // 子类用 super(...) 调用父类构造方法 } @Override void eat() { System.out.println(name + "吃骨头"); // 这里能用上 name } } public class Test { public static void main(String[] args) { Dog dog = new Dog("旺财"); dog.eat(); // 输出：旺财吃骨头 } } 一句话总结:抽象类的构造方法不是用来 new 抽象类自己的,而是子类 new 自己时,由 super() 调用来初始化从父类继承的字段。 ...
