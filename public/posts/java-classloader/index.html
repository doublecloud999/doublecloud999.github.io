Java 类加载器与类加载过程

ClassLoader 的职责、JDK 自带的三个类加载器与双亲委派机制，以及加载-链接-初始化三个阶段的细节。

一、ClassLoader 是什么#

类加载器是专门负责类加载的命令 / 工具，负责读取字节代码(.class 字节码文件)并转换为 .class 类的一个实例，将 .class 文件加载到 JVM 方法区中。

二、JDK 中自己带了 3 个类加载器#

  • 启动类加载器(父加载器)
  • 扩展类加载器(母加载器)
  • 应用类加载器

三、双亲委派机制#

父加载器找不到就找母加载器，如果都加载不到，就考虑从应用类加载器中加载，一直到加载到位置。

四、类加载的过程#

一定是发生在运行阶段的。

编译阶段，将 .java 文件编译生成 .class 字节码文件；然后运行，开始进行类加载。

加载 —— 链接 —— 初始化

4.1 加载#

  • 类加载器负责读取字节码，然后将字节代码转换为 .class 实例(从二进制字节流中提取出类的数据结构，比如常量池、字段、方法)
  • 然后将它加载到 JVM 的方法区(类的元数据，比如字段名、方法签名、访问权限等自动进入了内存)中
  • 在堆中创建一个对应的 java.lang.Class 对象，这个对象是方法区中的类元数据访问入口

4.2 链接#

  • 验证
  • 准备
  • 解析(在解析阶段会将符号引用替换成对应的直接引用)

4.3 初始化#

主要对静态域进行初始化。

两种初始化方式:

  1. 声明时直接指定初始值
  2. 通过静态代码块直接初始化值

初始化时机:

  • 创建对象的时候
  • 初始化某个类的子类的时候，该子类的所有父类都会被初始化
  • 调用某个类的静态方法时
