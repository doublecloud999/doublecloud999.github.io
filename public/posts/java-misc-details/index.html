一、return 里也能 new 对象#

return 的时候还能 new 对象。

假如声明一个方法的返回值类型是 Person(Person 是个类)，那么返回时既可以返回一个已有的 Person 对象，也可以返回 Person 类的子类对象。这个对象的来源有两种:

  1. 已有的对象
  2. 在 return 语句中 new 出来的对象

二、sc.close()#

在不再用 sc 读数据时调用，它会将底层的 System.in 也关闭。

为了代码安全，写项目时要写。

三、IDEA 快捷键#

  • 在括号内按 Ctrl+P，可以直接查看该填什么参数
  • 选中后按 Alt+Insert 生成 set/get 方法
    • 注意:对于 boolean 类型的变量，生成的 getter 方法名比较特殊，叫做 isXxx()
  • 按两次 Shift 调出界面 Search Everywhere(随处搜索)

四、main 方法中的 args#

public static void main(String[] args)

args 是一个 String[] 字符串数组:

  • 默认情况下长度为 0
  • 用来接收命令行参数，增强交互

五、编码与字节数#

在 ASCII 码中，一个英文字母不分大小写，都占用一个字节的空间。GBK 编码中一个中文汉字占两个字节。

编码一个英文字符一个中文汉字
ASCII1 字节不含中文
UTF-81 字节3 字节
Unicode2 字节2 字节

Java 用的是 Unicode 编码。
