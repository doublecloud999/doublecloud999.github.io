Java 多态

多态的定义、编译时多态(方法重载)与运行时多态(方法重写)的区别、运行时多态成立的三个条件,以及哪些成员不参与多态。
September 21, 2026 · 1 min · 47 words · doublecloud999

  • 二、运行时多态 —— 动态多态(方法重写 @Override)
    • 重点
    • 静态方法被子类隐藏

多态:允许不同的对象对同一个方法进行调用(同名方法在不同对象上表现不同)。

一、编译时多态 —— 静态多态(方法重载 Overload)#

编译的时候就确定用什么。

  • 必须在同一个类中
  • 方法名必须相同
  • 参数列表必须不同(包括类型 / 个数 / 顺序都可以不同,只要有一个不同就算不同)
  • 编译的时候通过参数确定调用哪个方法

二、运行时多态 —— 动态多态(方法重写 @Override)#

运行的时候才决定用什么。

成立条件:3 个缺一不可

  1. 继承关系:子类继承父类
  2. 方法重写:子类重写了父类的方法
  3. 父类引用指向子类对象:Person p = new Student() 或者 Person p = man_1;

子类 @Override 父类方法,名字和参数列表必须与父类一模一样;返回值类型必须与父类的返回值类型相同,或者是父类返回值类型的子类;访问权限不能比父类更严格。

重点#

  • 调用的时候调用的方法是子类定义的方法,不是父类定义的方法
  • 成员变量(字段)不参与多态,也不能被子类重写
  • 静态方法和 private 方法不参与多态,因为它们压根没法被子类重写(静态方法可以被子类隐藏)。它们绑定在类上,在编译阶段就被确定好了

静态方法被子类隐藏#

子类可以写一个跟父类方法名和参数列表都相同、返回值类型与父类相同或者是其子类、限制符号不比父类严格的静态方法,但是不能加 @Override 注解,这会直接导致编译报错。

而且这不叫重写,没有多态效果。
